## ALREADY-HAVE

Do not re-port these families:

- Kotlin callable signatures (#1495), Rust unit structs (#1513), Python aliased
  module imports (#1626), and Lua/Luau assignment-style functions (#1616/#1650);
- TypeScript `.js` specifier substitution, declaration-initializer ownership,
  affected/test-file unification, inheritance/import target-kind gates, orphan
  reference sweeping, and no silent fuzzy command substitution;
- safe host-global-chain handling and immutable/read-only index consumption;
- opt-in cross-context Explore dedup remaining disabled by default.

The built-in collection-method safety goal is valid, but do not copy `de5adba`
mechanically; see the regression warning below.

## N/A — implementation architecture differs

- FTS5 fallback #1532: Rust uses bundled SQLite with FTS5 as a required schema
  capability and should fail loudly if that contract is absent.
- Objective-C WASM preload #1628: native Rust grammar linkage has no selective
  WASM preload stage.
- old Git `<2.36` list behavior #1549: Rust does not use the same upstream
  `git ls-files` implementation path.
- upstream stale-index sync rejection #1842: Rust has a state-gated supported
  migration through `sync`.
- telemetry/GDPR/refresh-backup issues #1868–#1870: this product has no telemetry
  or upstream `install --refresh` behavior.
- `getDominantFile` hotspot #1864: the Rust Explore engine does not run that
  upstream whole-graph SQL path.

## DEFER — unreleased UI and large proposals

The UI/Screens/Steps/router family is substantial and still unreleased. At this
audit boundary it also intersects upstream regression issue #1794 and open PR
#1862, which is restoring call relations/Steps effects after overly broad member
call suppression. Therefore no Svelte workspace, loopback API, `navigates` edge,
or UI release asset is part of this correctness sync.

The Rust-side direction is an approved later epic: Svelte 5/Vite builds static
assets that a Rust loopback service embeds in the single binary; users and
`cargo install --git` do not need Node. Product design is separate from source
implementation. As of this dated audit, a top-level **CodeGraph** Penpot project
has been created through the browser, but CodeGraph file/board work is paused
while the shared Penpot MCP plugin is occupied by an active pt-tools design
session. The plugin's current-file/current-page/storage state is single-writer,
not transactionally isolated. KiroClaude will produce multiple design directions
after that writer releases the connection; the owner chooses one before
`DESIGN.md` is frozen or UI code begins.

Also deferred pending narrower evidence and stable interfaces:

- literal index/requested source ranges (PR #1841/#1867);
- Vue component contract (PR #1858);
- Android platform analysis (PR #1854);
- HDL/Verilog monolith (PR #1845; must be split);
- SQL/Dataform #1757, Perl #1739, and Cython #1819;
- Kimi/Devin installer targets #1859/#1860; and
- ambiguous prompt-keyword changes #1654 without measured recall impact.

## Regression warning: do not copy `de5adba`

Upstream `de5adba` suppressed built-in Map false edges by deleting all
identifier-rooted member call evidence. That removed real relationships and led
to #1794 and the corrective direction in PR #1844/#1862. The Rust port should
retain complete call-site evidence and allow only a resolver with type/import/
visibility proof to persist an edge.
