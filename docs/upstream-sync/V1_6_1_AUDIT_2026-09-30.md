- **Range:** `3ed73bc127323e63153bf6ec8354afa82ce36aaf..f4ddf508516332419ea3c95702810765936cf679`
  (colby `v1.6.1`, tagged 2026-09-29): 113 commits, 111 of them non-merge.
- **Baseline:** the 2026-09-15 integration snapshot audited in
  [`POST_V1_6_MAIN_2026-09-15.md`](POST_V1_6_MAIN_2026-09-15.md). Every commit
  in the range was classified against that tree by two read-only passes
  (resolution/extraction; MCP/CLI/installer/UI family), and each PORT was
  re-verified against the code before it was implemented.
- **Tracked release:** [`UPSTREAM.md`](UPSTREAM.md) advanced to `v1.6.1` on
  2026-10-01, once the ported rows shipped in codegraph-rs `v0.51.0` and the
  downloaded binaries were verified.
- **Kernel commits:** upstream's `codegraph-kernel` (MIT, `publish = false`)
  mirrors each TypeScript change for its native backend. They were read as
  reference only; none of them is a separate port.

Dispositions use the ledger rubric: **PORT**, **CORRECT** (the Rust port has the
feature in an older or divergent form), **ALREADY-HAVE**, **N/A** (TypeScript,
Node or upstream-only surface), **DEFER**, and **KEEP-RUST** (a deliberate,
documented divergence).

Findings outside the upstream range, recorded so the next audit starts from
them: callers/callees never followed `instantiates` edges (upstream #774/#804,
2026-06-11; fixed in #278), and Go field-chain calls such as
`c.store.Fetch()` still resolve through the last receiver segment, where
upstream reads the field's declared type (#1276/#1316); since #278 Go method
values use that field-type rule.

Two corrections found while porting, outside the upstream range but required
for the rows above: the Rust TSX and JSX specs did not delegate the
class-member hooks (a plain TSX field became a method), and JavaScript class
fields were named `<anonymous>` instead of by their `property` key (upstream
#808). Both are fixed in this PR.

KEEP-RUST divergences taken in this PR:

- a TS/JS member chain rooted at `this`/`super` through more than one field
  (`this.a.b.m()`) keeps its last segment (`b.m`, the #1496 port) instead of
  upstream's bare method name, which would let the name matcher bind the
  enclosing class's same-named method;
- a TS field whose name ends in `$` (`users$`) is a whole token for
  declaration lookup, where upstream's trailing `\b` rejects it;
- a `this.<field>` inside a method body counts only as `this.<field> = new T()`,
  so a same-named local or parameter never supplies the field type.

A Rust-only defect found by this pass: the watcher treats only `locked`/`busy`
errors as lock contention, but an index-lease timeout reports `timed out
acquiring permanent index lock`, so a long foreground `index` makes the watcher
drop the batch and count a failure. It landed with #1964 in #279.

Two more turned up while porting the explore rows. The CG-38 port windowed a
cluster with 60% of its room on the head whenever it held a focus, even a focus
the head already showed, where upstream gives the head the whole room first;
this was never recorded as a divergence and is corrected in #281. And the
completeness count read "1 files"; #2077 gives it upstream's wording.
