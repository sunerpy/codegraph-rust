# Community

This page lists where to ask questions, report problems and follow news about CodeGraph.

## Problems and suggestions

Report bugs and request features in [GitHub Issues](https://github.com/sunerpy/codegraph-rust/issues). Include the
output of `codegraph --version` and the steps that reproduce the problem.
